# TEAM_GUIDE.md — 팀원 시작 안내서

지도(`map.html`)와 홍보 카드(`card.html`)를 맡은 팀원을 위한 안내서입니다.
코딩을 처음 해도 따라 할 수 있게 순서대로 적었습니다.

> ⚠️ **지금은 아직 시작하지 마세요.**
> 팀장이 "뼈대 올렸어요(Phase 4 끝)"라고 알려주면 그때 2번부터 시작하면 됩니다.
> 그 전에 **1번(프로그램 설치)** 만 미리 해 두세요.

---

## 0. 한눈에 보기

- 내가 맡은 파일은 **딱 4개**: `map.html`, `js/map.js`, `card.html`, `js/card.js`
- 나머지 파일은 **열어 봐도 되지만 고치면 안 됩니다.** 바꾸고 싶으면 팀장에게 요청합니다.
- 팀장이 4개 파일의 **빈 뼈대**를 미리 만들어 둡니다. 나는 그 안을 채웁니다.
- 코드는 ChatGPT에게 받아서 **파일 전체를 통째로 바꿔 붙여넣는** 방식으로 작업합니다.
- 규칙은 전부 [CONVENTIONS.md](CONVENTIONS.md)에 있습니다. ChatGPT에게도 이 문서를 줍니다.

## 1. 처음 한 번만: 프로그램 설치

| 순서 | 할 일 | 어디서 |
|---|---|---|
| 1 | **Git** 설치 (설치 화면은 전부 "Next") | https://git-scm.com |
| 2 | **VS Code** 설치 | https://code.visualstudio.com |
| 3 | VS Code를 열고 왼쪽 네모 4개 아이콘(확장) → **Live Server** 검색 → 설치 | VS Code 안 |

설치가 끝나면 VS Code에서 `터미널 → 새 터미널`을 열고, 아래 두 줄을 **내 이름·내 이메일로 바꿔서** 한 번만 입력합니다.

```bash
git config --global user.name "내 이름"
```

```bash
git config --global user.email "깃허브에 가입한 이메일"
```

## 2. 저장소 받기 (git clone)

1. VS Code에서 `터미널 → 새 터미널`을 엽니다.
2. 파일을 둘 곳으로 이동합니다(예: 바탕화면).

   ```bash
   cd Desktop
   ```

3. 팀장이 채팅방에 올려 준 주소로 내려받습니다. (아래 주소는 모양만 보여주는 예시입니다)

   ```bash
   git clone https://github.com/팀장아이디/coffee-landlord.git
   ```

4. VS Code에서 `파일 → 폴더 열기` → 방금 생긴 `coffee-landlord` 폴더를 엽니다.

## 3. 내 컴퓨터에서 사이트 보기

> ❗ **HTML 파일을 더블클릭해서 열면 데이터가 안 보입니다.**
> 우리 사이트는 `data/` 폴더의 JSON 파일을 읽어 오는데, 더블클릭으로 열면 브라우저가 보안 때문에 파일 읽기를 막습니다. 꼭 아래 방법으로 여세요.

1. VS Code 왼쪽 파일 목록에서 `index.html`을 **마우스 오른쪽 클릭**
2. **Open with Live Server** 클릭
3. 브라우저에 `http://127.0.0.1:5500/index.html` 이 열리면 성공
4. 파일을 저장(Ctrl+S)하면 화면이 자동으로 새로고침됩니다.

폰 화면처럼 보려면: 브라우저에서 `F12` → 왼쪽 위 폰 모양 아이콘 클릭.

**지도가 안 뜰 때**: 카카오 지도는 팀장이 등록해 둔 주소에서만 뜹니다. 주소창의 주소가 `http://127.0.0.1:5500` 또는 `http://localhost:5500` 이 아니면(숫자가 다르면) 팀장에게 그 주소를 알려주세요.

## 4. 매번 작업하는 순서

```
① 받기(pull) → ② ChatGPT와 작업 → ③ 화면 확인 → ④ 올리기(add·commit·push)
```

**① 작업 시작 전 — 최신 내용 받기**

```bash
git pull
```

**② ChatGPT에게 코드를 받아서 붙여넣기**

- ChatGPT가 준 코드로 **파일 전체를 바꿉니다**: 파일 열기 → `Ctrl+A`(전체 선택) → `Ctrl+V`(붙여넣기) → `Ctrl+S`(저장)

**③ Live Server로 화면 확인**

- 화면이 이상하거나 안 뜨면 `F12` → **Console** 탭의 빨간 글씨를 복사해서 ChatGPT에게 붙여넣으세요.

**④ 작업이 끝나면 바로 올리기** (지도 작업을 했을 때 예시)

```bash
git add map.html js/map.js
```

```bash
git commit -m "[내이름] 지도 검색창 추가"
```

```bash
git push
```

- `git add` 뒤에는 **내가 고친 내 담당 파일만** 적습니다. (`git add .` 은 쓰지 않기)
- 커밋 메시지는 **`[이름] 무엇을 했는지`** 모양으로.

### ChatGPT와 일할 때 요령

- **대화가 길어지면 ChatGPT가 규칙을 잊습니다.** 이상한 코드(없는 함수, React 등)를 주기 시작하면 새 대화를 열고 시작 프롬프트를 다시 보내세요. 이때 ③에는 **지금 내 컴퓨터에 있는 최신 파일**을 붙여넣습니다.
- 한 번에 하나씩 부탁하세요. "검색창 먼저" → 확인 → "마커 표시" → 확인.
- 에러가 나면 `F12 → Console`의 빨간 글씨를 그대로 붙여넣으세요.
- ChatGPT가 "common.js를 이렇게 고치세요"라고 하면 **따르지 말고** 6번 방법으로 팀장에게 요청하세요.
- API 키를 ChatGPT에게 붙여넣지 마세요.

## 7. 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 화면에 데이터가 하나도 안 보여요 | HTML을 더블클릭으로 연 것입니다. **Live Server**로 여세요(3번). |
| `git push`가 거부돼요 (rejected) | 다른 사람이 먼저 올린 것입니다. `git pull` 한 다음 다시 `git push`. |
| `git pull` 했더니 충돌(conflict)이 났대요 | 건드리지 말고 화면을 캡처해서 팀장에게 보내세요. |
| 지도가 회색이거나 안 떠요 | 주소창 주소를 확인해서 팀장에게 알려주세요(3번 맨 아래). 인터넷 연결도 확인. |
| 글자가 깨져요 | VS Code 오른쪽 아래가 `UTF-8`인지 확인하세요. |
| 내가 고친 게 화면에 안 바뀌어요 | 저장(Ctrl+S)했는지 확인하고, 브라우저에서 `Ctrl+Shift+R`(강력 새로고침). |

## 8. 하면 안 되는 것 (요약)

- ❌ 내 담당이 아닌 파일 수정
- ❌ 숫자·리츠 이름·주소를 코드에 직접 써넣기 (가짜 데이터 금지 — 교수님이 싫어하십니다)
- ❌ "추천", "보장", "무조건", "대박" 같은 표현 (CONVENTIONS.md 6장)
- ❌ React 등 프레임워크·라이브러리 사용
- ❌ 카카오 장소 검색 결과 저장
- ❌ API 키를 코드·카톡·ChatGPT에 붙여넣기 (카카오 JavaScript 키는 팀장이 `map.html` 뼈대에 넣어 둡니다)
